## What changed in the rules

| Rule | Before | After (metric labels only) |
|---|---|---|
| `GraphLoaderPlanResourceWaitHigh` | `sum by (le, run_id)` (a target label) | `sum by (le, execution_id)` |
| `GraphLoaderNoRecordsConsumed` | `unless on(instance)`, `sum by (instance)` | `unless on(exporter)`, `sum by (exporter)`; annotation shows the exporter |
| `GraphLoaderPlannedRunStalled` | annotation `run_id` | annotation `execution_id` (and run_id) |
| `GraphLoaderDlqBacklogHigh` | `max by (kind, name)` | `max by (kind, name, execution_id)` |
| `GraphLoaderDlqBacklogAbsent` | join on `(name, run_id)` | join on `(name, execution_id)` |
| `GraphLoaderRetryStalled`, `GraphLoaderWriteOutage`, `GraphLoaderRetryRateHigh` | `by (…, run_id)` | `by (…, execution_id)` |
| `GraphLoaderPlannedModeDeadlockObserved` and every other rule | — | unchanged (selectors name no identity label; the one-hour history survives the exporter leaving) |
| New: `GraphLoaderTargetDown` | — | `up{job="graph-loader"} == 0`, 1m (per-target paths, and the one aggregate target) |
| New: `GraphLoaderExporterScrapeFailed` | — | `graph_loader_exporter_up == 0`, 1m (aggregated path, per child) |
| New: `GraphLoaderDuplicateScrape` | — | `count by (exporter) (count by (exporter, job) (graph_loader_process_up)) > 1`, 2m |

`run_id` is reusable and is empty on the Docker roles that never received `GRAPH_LOADER_RUN_ID` (S8), so no rule groups or joins on it; the rules use `execution_id` and `exporter`. Docker-path health is `up` by container/instance (Docker SD cannot derive the incarnation exporter).

Dashboard: no pinned datasource uid anywhere (a `datasource` variable of type datasource, referenced as `${datasource}` by every panel, target and query variable); every panel filters on `execution_id`; a `run_id` variable only narrows the execution list (`label_values(…{run_id=~"$run_id"}, execution_id)`, no `allValue`, so "All" expands to the narrowed list); a `job` variable for the `up` query; the lag panels follow the execution variable (the CLI's series now carry it); legends of un-aggregated series show `{{exporter}}`; the "plan resource wait by run" panel became "by execution"; the scrape-health table has query A `up{job=~"$job"}` and query B `graph_loader_exporter_up{execution_id=~"$execution_id"}`.
