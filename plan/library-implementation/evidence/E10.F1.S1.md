## Not covered / open

- **No arm64 run and no macOS run**; Linux amd64 only, CPython 3.12.3. The guide makes no platform claim of its own and points to the README support section (written in E10.F1.S2).
- The version printed is `0.1.0a1.dev0` (development wheel); the guide says `0.1.0a1`, the D03 target. Install from the index cannot be exercised before upload; E11/E12 (TestPyPI and PyPI install checks) must re-run this guide against the real artifact.
- The loading step (`graph-loader start`) is deliberately not a quick start: it needs the versioned images, which exist only as local candidates until E11. The guide says so and links to the bulk-load guide. The README quick start (checkout/Compose based) is rewritten in E10.F1.S2.
- Kafka versions other than 7.7.0 and brokers with security settings were not tried; the guide shows a plaintext address only.
- `docs/QUICKSTART.md` links to a README section `#support-and-limits` that E10.F1.S2 creates; until then that link dangles.
