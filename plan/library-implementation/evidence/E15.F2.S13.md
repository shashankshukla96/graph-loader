* The old `file_sd` example in PROCESS_RUNTIME had a wildcard in a directory element, which Prometheus refuses (found live in S12).
* `GRAPH_LOADER_STATUS_INTERVAL_S` is documented as the roles' snapshot cadence; `GRAPH_LOADER_RUNTIME` has two meanings (operator default for `--runtime`; set to `process` by the process runtime for the roles).
* The old MONITORING text said the metric labels exclude `run_id` and that the stack binds `0.0.0.0` with `admin`/`admin`; both were wrong after E15 and are corrected.
