## The contract

* **Extras (D15-4, decision D05 as amended).** `sql = ["SQLAlchemy>=2.0.30,<3"]`, `postgres = ["SQLAlchemy>=2.0.30,<3", "psycopg[binary]>=3.1.12,<4"]` (binary wheels: no system libpq). The floors are the lowest versions on which the SQL test files pass (fresh venv with SQLAlchemy 2.0.30 and psycopg 3.1.12: `test_status_sql`, `test_status_outbox`, `test_status_command` 82 passed, 37 skipped = the PostgreSQL cells that need a server; the first psycopg with CPython 3.12 binary wheels is 3.1.12). Upper bounds follow the next major. Base dependency list: unchanged.
* **Approved resource list** (`RESOURCE_FILES`): the two bundled schemas plus the 17 monitoring files, explicit. `inspect()` first compares the checkout's non-Python package files with the list (`checkout resources differ from the approved list`), then requires the wheel to contain exactly modules + those resources + the metadata files, and the sdist exactly those plus the finite input list.
* **Approved extras** (`APPROVED_EXTRAS`): `Provides-Extra` must equal `{sql, postgres}`; `Requires-Dist` must equal the base dependencies plus the extras' requirements with `extra == "<name>"` markers; `pyproject.toml`'s `optional-dependencies` must equal the list. `scripts/verify_installed.py` (`APPROVED_EXTRAS`) checks `Provides-Extra` of every lane wheel the same way.
* **Optional modules** (`OPTIONAL_MODULES`): exactly one module imports an optional dependency at import time, `neo4j_graph_loader/status/sql_store.py` (SQLAlchemy). The cold-import probe (`probe(..., extras=...)`) imports every OTHER module on a base install, requires `sql_store` to fail with a `ModuleNotFoundError` naming exactly `sqlalchemy` (and to import, hash-checked, when an extra is installed), and requires the distributions of extras that were not requested (`sqlalchemy`, `psycopg`) to be absent. `test_every_optional_module_is_the_only_one_importing_its_dependency` keeps any other module from importing them at module level.
* **Metric catalogue**: 32 families since S8 (`scripts/validate_monitoring.py`, `utils/metrics.py`, the catalogue tests).
