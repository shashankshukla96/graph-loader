## Findings

- **Product:** none. One behaviour worth recording: publishing both arrival topics at once, before the fleet starts, gives a nondeterministic last value for pairs present in both topics (582 of 783 pairs ended with the older topic's value in two of three exploratory runs). This is the documented `topic_conflict: arrival` warning ("resolve in arrival order, which is nondeterministic"), not a defect; the maintained test's sequencing (b fully dead-lettered, then a) is what makes the result deterministic, and the test asserts that sequencing.
- **Harness changes this story** (red runs kept under `var/e09-validation-20261028/s4/` and `/home/shashank/e09-s4-runs/`): the query-log detector gained (a) a terminal `failed` record for a query that fails or is terminated (ERROR level, completion format plus failure text; S1 already needed this) and (b) a `rejected` record for a statement Neo4j refuses before running it (ERROR, transaction id -1, database `<none>`, no start record; the Cypher 25 feature probe of the `native_disjoint` writer), both fail-closed with controls (query-window controls grew by 7 IDs); queries a killed client leaves open are declared as orphans by the test that kills it (`query_window.declare_orphans`, scoped to the server epoch) so later strict captures accept exactly those and still reject any new open query (2 controls); the Neo4j query-log read bound is now 32 MiB, because the arrival runs add about 2.7 MB each to the one log the whole lane shares. `test_service_load_bulk.py` (S1) declares its orphan and counts only new ones. `stream_run.py` generalises the S2 stream runner.
- **Own test mistakes** (red runs): `x-1` undeclared `since` property (the product correctly dead-lettered every row as malformed); arrival exploration published both topics at once (above); `final-1` asserted `missing_both` only (the documented blocked reason also occurs); `final-2` reused a topic tag between the S2 and S3 files and a killed S1 writer's open query broke every later strict capture; `final-3` counted an earlier repeat's declared orphan as new. None changed a product result.
