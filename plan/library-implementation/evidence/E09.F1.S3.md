## Addendum (2026-10-31): `native_disjoint`

The orchestrator asked for either a small `native_disjoint` classic run or a recorded reason. Executed result (test `test_s3_native_disjoint_is_refused_by_a_plain_start_and_fails_closed_on_neo4j_5_26`, passing in `/home/shashank/e09-s4-runs/final-4/`, the lane run of S4 which also re-proves S3):

- A plain `start --mode bulk` with `execution.mode: native_disjoint` types is refused before any container launches, with `…native_disjoint, which neither zero-wait mode supports; pass --edge-classic…`; nothing is written.
- With `--edge-classic` the node loaders run and the edge loader exits 1 with `Execution mode native_disjoint requires Cypher 25; server=Neo4j/5.26.32`: Neo4j 5.26 rejects the writer's `CYPHER 25 RETURN 1 AS supported` probe (logged once at ERROR; the detector records it as a `rejected` query). The run fails closed, no relationship is written, all containers are removed.
- Disposition (orchestrator, 2026-10-31): `native_disjoint` is excluded from the guarantees on the D04 Neo4j 5.26 target; the docs (`BULK_LOAD.md`, `USAGE.md`, CLI help) say `--edge-classic` is the only way to run it and do not mention the Cypher 25 requirement; the correction is E10.F1.S2.

The S3 results above were obtained at `s3/final-1`; the same tests pass again, unchanged in behaviour, in `s4/final-4` (117 IDs, inventory `0a62ce48…`). The classic test file gained the `native_disjoint` test, and `stream_fixture.py` a `mode` option; the earlier S3 run is superseded by that lane run for "final bytes".
