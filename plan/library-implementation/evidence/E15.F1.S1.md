## Public contract (for review)

* `schema_version` = 1 (integer); additive-only within it. Both schemas are JSON Schema 2020-12 and closed (`additionalProperties: false`); `$id` `urn:neo4j-graph-loader:schema:{status,event}:1`.
* Identity: `execution_id`, `incarnation` = `uuid4().hex` (32 lowercase hex; E14's registry format). `run_id` = the CLI `--run-id` charset, **nullable**. Phase ids = the derived sub-run ids (`phases[]`: `phase_id, kind, index, edge_type, state, started_at, finished_at`). Roles (`roles[]`): `role, name, replica, incarnation, restart_count, state, container_id, pid, started_at, finished_at, exit_code, exit_reason, last_error`.
* State: `starting|running|stopping|succeeded|failed|stopped`; transition table in `model.TRANSITIONS`, terminal states final. `outcome` = `{exit_code, reason, error}`. Overlapping `activities` object keyed `planning|nodes|edges|draining|stream`, each `{state: pending|running|succeeded|failed|stopped, started_at, finished_at, updated_at}`.
* Telemetry shape: `types[]` (`kind` node|edge, `name`, plus any of `records_written, ready, retry_written, retry_redlq, retry_parked, lag, plan_chunks_done, plan_chunks_total, rejected, dlq_lag, parked_size`) and `totals`; each present field is `{value, observed_at, source[, lower_bound]}` or `null` (unknown); absent = not applicable. `telemetry: {available, reason}` carries the reason when snapshots are impossible. Also `labels`, `history_incomplete`, `versions`, `host`, `pid`, `revision` (strictly increasing, 1-based), `heartbeat_at`.
* Events: `schema_version, execution_id, seq (gap-free from 1), ts, type` + fields. Types: `execution.started`, `execution.run_id`, `execution.state`, `execution.finished`, `activity.state`, `phase.started`, `phase.finished`, `role.started`, `role.exited`, `role.oom`, `error`, `gap` (`from_seq,to_seq,count,reason`; its `seq` = `from_seq`).
* Credentials: error text is redacted (URL passwords, `password|token|secret|api_key=...`) before entering snapshot or event.
