# E04.F2.S5 — Private complete-frame nonblocking transport

Replaced worker Pipe traffic with owned socketpair frames. Parent and child close
duplicate endpoints; constructor/start failures close owned endpoints. Parent
reads header/body incrementally and handles short writes/backpressure through
selector waits <=100ms, invoking supplied control before/after waits and codec.
No receiver helper thread/process is introduced. Child-only initial task pickle
retains the explicit source serialization/submission exclusion; parent replies
and all later commands use a closed binary tagged codec, never pickle loads.

Closed types are exact builtins, finite floats, bounded arbitrary integers,
bytes/strings, list/tuple/dict, 1D uint32/uint64 arrays and the owned ChunkSpec
class. Subclasses/user objects/object arrays/unsupported dtypes never invoke
reduce/property/construction callbacks in the parent. Defaults:64MiB frame and
aggregate scalar/array bytes,1MiB scalar (including integer representation),
32MiB array,1M nodes,depth64. Size/shape/tag/truncation/EOF/corruption failures
are explicit; deadline checks surround codec work and occur every1024 nodes.
CPU preemption and arbitrary excluded source/client callbacks are not claimed.
Decoded container overhead is separately bounded by nodes/depth; buffer copies
are bounded by frame/allocation caps. E08 still owns supported-platform maxima.

Tests round-trip actual command/results including maximum2^22 uint32 counter,
packed candidates, ChunkSpec and encoded temporal hub values; all four numeric
array endianness/widths preserve values. Exact64MiB frame and over-limit control,
small exact/over scalar/depth/node/cumulative bounds, callbacks/corruption,
partial-progress read/write and fake absolute-clock checks pass.
Externally supervised real child controls exercise >socket-buffer partial reply
stall and nonreading peer, both timeout and cancellation. They assert prompt
private interruption, child reaping/endpoint closure and fixture timer cleanup;
outer supervisor independently owns the entire client process group.

Raw focused records: var/e04-validation-20261018/s5-tests.log; interpreter is the
fresh dev environment. Independent report records exact count/findings/rechecks.
The S3 public errors/clock integration and S4 aggregate cleanup are **not** claimed
