  `--rename` by `sha256:<digest of the old id>` (entry: `new_id`, `old_id_sha256`, `reviewed`, `reason`); the old id string is in the private sidecar
  (`reviewed_id_renames.old_ids`). New functions `conceal_renames`, `resolve_renames`, `concealed_problems`, mode `--conceal-renames OLD_ID…` (applied to the
  already frozen file, no collection needed). `compare_inventories` derives the renames from the concealed records when none are passed, and `check` refuses a
  malformed or inconsistent concealed record, a concealed old id that is still collected, and any `192.168.x.x` address anywhere in the file.

  the freeze logic itself (`freeze`, `collect`) did not change, so no second host sitting was needed. A Mac collection equals the inventory except for the platform signal id.
