# E04.F2.S1 — Public ownership and lifecycle

Public-module tests and LIBRARY_API documentation expose the existing one-shot,
idempotent-start/close, configured-path and exclusive-output contracts without
adding a cancellation claim. Explicit try/finally usage preserves canonical
planner identity. Live/stale locks are never guessed from PIDs; valid retries
clear stale plan/failure state only after claiming ownership. Topic ownership is
caller-owned for factory/create_topic=False, convenience-owned on creation,
retained on success, best-effort deleted on ordinary failure; deletion errors
remain logged without replacing the source failure.

New tests call only approved public schema/planning modules for application
behavior, using test-only fake Kafka helpers. They cover closed/repeated calls,
live owner and manual stale recovery, wrong path, old output replacement,
created/caller topic success/failure and cleanup-error visibility. Inherited B1,
spawn/external planner and abort regressions are included in the focused lane.
