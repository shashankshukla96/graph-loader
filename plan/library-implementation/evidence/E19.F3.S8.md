## What the tool does

`export_public.py prepare --source WORKTREE_OR_REPO [--commit SHA] --message TEXT --expect-parent none|SHA --quarantine-root DIR [--allow ...] [--secret-file ...] [--mapping ...]`

1. The quarantine root must lie outside both repositories (the private worktree and the main checkout); otherwise refused.
2. The remote is checked first. `shashankshukla96/graph-loader` is refused in every spelling (https, ssh, scp style, with `.git` or without, userinfo, upper case, trailing slash, port); only `Neburyx/graph-loader` or, for the tool's own tests, a local bare repository passed with `--local-remote` is accepted, and a local bare repository can never be the private one.
3. A fresh read-only clone of the public repository goes into `QUARANTINE/clone`. The state is compared with `--expect-parent` (`none` for the empty repository, or the last approved SHA); a mismatch is an error.
4. The full replacement tree is built with `export_guard.materialize` (public set, D19-2) from the worktree or from a named private commit (`git archive` into scratch), the clone's working tree is emptied and filled with it, so a file absent from the manifest is deleted in the public tree.
5. The guard runs on the tree before any commit; on a hit the whole quarantine is deleted and the hits (file, line, rule) are printed (exit 1). Then the message is checked, the commit is made with the D19-1 identity set in the clone's own config only, the guard runs again on the new commit (author, committer, trailers, tree), and only then `.git/export-validated` records the commit.
6. `remote.origin.pushurl` is set to a disabled value, `GIT_CONFIG_GLOBAL=/dev/null` is used for every git call of the tool, so the user's global git configuration is neither read nor written. The tool contains no `push`, `send-pack` or `fetch --update` code (a test scans the source).
7. It prints the file list and the diff paths (`report/files.txt`, `report/diff.patch`), the proposed reference (`refs/heads/main`) and the commit, and appends the mapping record (private head, private source, SHA-256 of the materialized tree, public parent, public commit, public tree, remote, status). Nothing is pushed.
8. `tag --quarantine DIR --name vN --target SHA --message TEXT`: only a commit recorded in `export-validated`, a version-shaped name, a message that passes the guard, an annotated tag with the public identity as tagger, `check_tag` run afterwards (the tag is deleted when it fails). `discard` deletes only a directory that carries the `.export-quarantine` marker.
