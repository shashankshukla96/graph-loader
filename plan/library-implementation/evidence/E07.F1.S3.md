## Private dotenv collection defect

During inventory discovery the author found that the original developer smoke
module eagerly parsed the project's private `.env` at import. Earlier source
discovery collections therefore loaded it, contrary to the handoff constraint;
no credential values appeared in output and the file was not written. This is
recorded rather than claiming it never happened. Subsequent collection uses the
repair: only execution of an actual smoke-marked check loads those settings.
Unit/collection imports do not. Existing precedence and missing-password checks
are preserved; a new import regression passes. The original behavior was
reproduced from Git source with file access blocked **before** any private read.
The smoke service tests have not been run.
