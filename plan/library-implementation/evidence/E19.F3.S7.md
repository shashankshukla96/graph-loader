## What the guard is

`export_guard.py materialize | tree | commits | tags` with `--allow`, `--secret-file` (repeatable) and `--json`. It fails closed (exit 1 on any hit, 2 on a malformed allow file).

- **Entries.** Only regular files of mode 100644 or 100755. A symlink, gitlink or submodule (modes 120000, 160000), a directory entry, any other mode, a `.git` directory or file or a `.gitmodules` inside the tree is refused. The tree provider reads a materialized directory
  (symlinks and nested `.git` found on disk); the git provider reads `ls-tree` and `cat-file` of a commit.
- **Text and binary.** A file with a NUL byte in its first 8 KB or an archive magic (zip, gzip, bzip2, xz, 7z, rar, zstd) is binary and passes only by exact path and sha256 from the reviewed list; anything else must be valid UTF-8.
- **Paths.** Every path must lie in the public set (D19-2: the top-level directories `src tests docs scripts examples monitoring config` and the listed top-level files; `docs/PYPI_*` records, caches, `.egg-info` and `__pycache__` excluded; everything else excluded by default), and every component is checked
  (empty, `.`/`..`, control characters, backslash, leading dash, trailing dot or space, Windows reserved names, non-NFC, over 255 bytes, case collisions). The denylist runs on paths too.
- **Denylist, case-insensitive, per line:** `claude codex anthropic openai gpt- subagent cartographer .agents .claude co-authored-by`; `plan/(v[0-9]|library-implementation|[a-z0-9-]+\.md)` (product identifiers such as `graph-loader-edge-plan/1`, prose like `plan/chunk` and the word "orchestrator" pass);
  RFC 1918 addresses (not inside longer numbers or versions); `/Users/` and `/home/`; any e-mail address other than the public contact and the noreply address; credential patterns (private-key and `-----BEGIN` headers, `AKIA…`, `gh[pousr]_…`, `github_pat_`, `pypi-AgE`, `xox[abpr]-`,
  URL userinfo, `password|secret|token` with a quoted literal value). A credential hit never prints the matched text.
- **Private credential values.** `--secret-file` reads private files at run time (`.env`/ini style `KEY=value` and `key: value` for sensitive key names, and JSON string values under sensitive keys with a Docker `auth` also decoded), keeps only sha256 hashes in memory and flags any token of the tree whose hash matches; the report names the file and the first
  12 hex characters of the hash, never the value. A value that the public `.env.example` documents is not a secret; `guard-allow.json` also lists `documented_defaults`.
- **Allow-entries** are exact: `{rule, path, line_sha256, reason}`; wildcards, directory paths, `*` as a rule, a missing or short reason or extra fields are refused when the file is loaded; an entry matches only that rule on that path on a line with that text; **an entry that matches nothing is an error**.
- **Commits** (`commits`, `check_commit`): author and committer exactly `Shashank Shukla <39862387+shashankshukla96@users.noreply.github.com>`; no signature, merge-tag or encoding header; no trailer (`git interpret-trailers --parse` and the usual keys); the message passes the denylist;
  every parent is the last public commit (`--parent-ok`) or an already validated commit; the tree of each commit is scanned. **Tags** (`tags`, `check_tag`): lightweight tags refused, tagger must be the identity at every level of a tag chain, message passes the denylist, no signature block, the peeled target
  must be a validated commit and all its ancestors validated.
- `materialize WORKTREE DEST` copies the public-set files of a worktree (tracked or new, not ignored, present on disk) into a new directory outside the worktree: the full replacement tree that S8 builds on.
