## Key Logic / Implementation Details
- Add `kafka` service to the Story 2 Compose baseline using `confluentinc/cp-kafka:7.7.0`, retaining the existing Neo4j service unchanged.
- Configure one combined broker/controller in KRaft mode: `KAFKA_NODE_ID: 1`, `KAFKA_PROCESS_ROLES: broker,controller`, `KAFKA_CONTROLLER_QUORUM_VOTERS: "1@kafka:29093"`, `KAFKA_LISTENERS: "PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:29093,INTERNAL://0.0.0.0:29092"`, `KAFKA_ADVERTISED_LISTENERS: "PLAINTEXT://localhost:9092,INTERNAL://kafka:29092"`, `KAFKA_LISTENER_SECURITY_PROTOCOL_MAP: "PLAINTEXT:PLAINTEXT,CONTROLLER:PLAINTEXT,INTERNAL:PLAINTEXT"`, `KAFKA_INTER_BROKER_LISTENER_NAME: INTERNAL`, and `KAFKA_CONTROLLER_LISTENER_NAMES: CONTROLLER`.
- Set single-broker replication and transaction constraints: `KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1`, `KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR: 1`, and `KAFKA_TRANSACTION_STATE_LOG_MIN_ISR: 1`; enable local topic creation with `KAFKA_AUTO_CREATE_TOPICS_ENABLE: "true"`.
- Use the fixed 22-character Base64 KRaft `CLUSTER_ID: "MkU3OEVBNTcwNTJENDM2Qk"`; add a comment explaining that it must be generated by `kafka-storage random-uuid`, not replaced with a human-readable string.
- Map ports 9092 (host clients) and 9101 (JMX), configure `KAFKA_JMX_PORT: 9101` and `KAFKA_JMX_HOSTNAME: localhost` so the exposed JMX port has a listener, mount `kafka_data:/var/lib/kafka/data`, attach the service to `graph-loader-net`, and declare the `kafka_data` named volume.
- Add a `kafka-broker-api-versions --bootstrap-server localhost:9092` healthcheck with the required 10-second interval/timeout, 10 retries, and 30-second start period.
